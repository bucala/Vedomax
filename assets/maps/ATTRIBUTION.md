# Map data

Country outlines: Natural Earth, 1:110m Admin 0 countries, public domain. [Source](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson), [terms](https://www.naturalearthdata.com/about/terms-of-use/). Downloaded 2026-10-26; used without changes to geometry.

City locations: GeoNames `cities15000.zip`, downloaded 2026-10-26. [Source](https://download.geonames.org/export/dump/cities15000.zip), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Selected records are retained in `assets/content/places.json`; each map question records its GeoNames URL. Coordinate values are unchanged. Display names are shortened for New York and clarified for Washington, D. C.

Maps are simplified educational illustrations and are not intended for navigation or boundary determinations.
